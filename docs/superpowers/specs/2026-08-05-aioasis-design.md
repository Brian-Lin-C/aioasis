# AI绿洲（aioasis.top）设计规格

- 日期：2026-08-05
- 状态：已与需求方确认（含 4 项高级感放大器）
- 域名：aioasis.top
- 部署目标：Vercel（后期绑定自定义域名）

## 1. 产品定位

个人品牌枢纽站：**AI绿洲 / AI OASIS**。

- 站主身份：AI 爱好者/学习者 × AI 开发者/创作者（探索者 × 创作者）
- 功能复合：个人品牌主页（主入口）+ AI 工具导航站 + 博客内容站
- 语言：中文为主，标题/标语/元数据中英混排
- 核心标语：在数字沙漠里，种一片自己的绿洲

## 2. 视觉系统 —— "一盏绿洲灯照亮整片夜沙漠"

核心概念：整个画面保持近乎全黑，唯一的光源是"绿洲"本身，用明暗对比（chiaroscuro）制造电影感。克制的单一强调色贯穿全站。

### 2.1 色彩

| 用途 | 色值（设计基线，实现时微调） | 说明 |
| --- | --- | --- |
| 页面底色 | `#050807` / `#0A0F0D` | 近黑带绿底调，非纯黑 |
| 主强调色 | `#3DF5A6` 附近 | 翡翠极光绿：CTA、悬停态、绿洲光晕 |
| 辅色 | `#E0B869` 附近 | 沙金：坐标、编号、星点等沙漠元素 |
| 主文字 | `#ECEAE5` | 暖米白 |
| 次级文字 | 灰绿（由主文字降透明度派生） | 摘要、元信息 |
| 语义色 | 自主色同温度/饱和度/亮度阶梯派生 | 不另起新色相 |

### 2.2 字体

- 拉丁展示体：Space Grotesk（几何无衬线），用于超大标题
- 中文：系统黑体栈 `"PingFang SC", "Microsoft YaHei", "Noto Sans SC"`（Google Fonts 加载时 `font-display: swap`）
- 混排规则：`'Space Grotesk', 'PingFang SC', 'Microsoft YaHei', sans-serif`——中文绝不由纯拉丁字体渲染
- 元数据/编号/坐标：JetBrains Mono 等宽体，11–12px，大写 + 加宽字距
- 中文不使用伪斜体；强调用字重、颜色、字距实现

### 2.3 材质与工艺细节

- 全站极淡胶片颗粒（film grain）覆盖层，`pointer-events: none`
- 自定义 `::selection` 选区颜色（翡翠绿底 + 黑字）
- 自定义滚动条
- 自定义 favicon（SVG，绿洲/星点意象）
- 无摄影图依赖：字体、留白、动效扛起全部质感

## 3. 页面结构（4 类页面）

### 3.1 首页 `/`（沉浸式长滚动）

1. **Preloader**：JetBrains Mono 百分比计数 `00% → 100%` + "LOCATING OASIS…"，完成后擦除进入
2. **Hero**（满视口 Canvas 场景）：
   - 星尘持续闪烁漂浮（环境运动）、远处沙丘剪影分层、翡翠色极光光晕缓慢呼吸
   - 鼠标视差、偶发流星
   - 中央超大 `AI OASIS`（流式字号，近满视口宽）+ `AI绿洲`
   - 副标语"在数字沙漠里，种一片自己的绿洲"
   - 底部滚动指引
3. **关于区**：`ABOUT / 关于这片绿洲` —— 探索者 × 创作者身份陈述
4. **导航精选**：`STATIONS / 绿洲驿站` —— Top 8 AI 工具卡片，SVG 描边框悬停流动亮起
5. **博客精选**：`WRITINGS / 最新观测` —— 最新 3 篇文章卡片
6. **页脚**：marquee 滚动灯带、GitHub（github.com/brian-lin-c）、`© 2026 AI绿洲`

### 3.2 导航页 `/nav`

- 全部分类：对话、绘画、视频、编程、办公、开源模型等
- 分类筛选 + 关键词搜索
- 工具卡片：名称、一句话简介、分类标签、外链

### 3.3 博客列表 `/blog`

- 文章卡片流：标题、日期、标签、阅读时长、摘要

### 3.4 文章详情 `/blog/:slug`

- Markdown 渲染，排版优先：正文宽度 28–32 个汉字、动态行高、代码块等宽体

## 4. 动效系统

桌面端完整实现，触摸设备优雅降级（隐藏自定义光标、减弱视差）。

- **Lenis** 惯性平滑滚动 + **GSAP ScrollTrigger**
- **遮罩上滑揭示**：区块标题从 `translateY(105%)` 滑入（overflow hidden 容器），电影字幕式
- **自定义十字光标**：跟随鼠标的十字线；悬停工具卡显示"进入"，悬停文章显示"阅读"（仅桌面）
- **磁性按钮**：CTA 与导航项鼠标靠近时轻微吸附，离开回弹
- **缓动规范**：自定义贝塞尔 `cubic-bezier(0.16, 1, 0.3, 1)`，时长 0.6–1s；禁止默认 ease 与 200ms 快动效
- **页面转场**：擦除式切换
- **导航菜单**：等宽体编号式（`01 首页 / 02 驿站 / 03 观测`）
- 尊重 `prefers-reduced-motion`

## 5. 高级感放大器（已确认纳入）

1. **极端字号对比**：Hero 标题近满视口宽（`clamp()` 流式字号），元数据压至 11–12px 等宽小字
2. **物理感缓动**：见动效规范
3. **磁性按钮**：见动效系统
4. **排版洁癖**：中文字距微调、标点悬挂、行高随字号动态计算、正文限宽

## 6. 技术与内容架构

- **栈**：Vite + React + TypeScript + Tailwind CSS + shadcn/ui；GSAP + Lenis + Framer Motion；Canvas 原生手绘星场（不引重型 3D 库）；Lucide 图标
- **路由**：React Router（`/`、`/nav`、`/blog`、`/blog/:slug`）
- **导航数据**：`src/data/tools.ts` 结构化文件（分类、名称、简介、URL、精选标记），增删只改数据
- **博客**：`src/content/blog/*.md` + frontmatter（title/date/tags/excerpt），Vite `import.meta.glob` 自动收录——丢一个 `.md` 即发布
- **启动内容**：
  - 约 30 个 AI 工具条目（覆盖对话、绘画、视频、编程、办公、开源模型等分类，其中 8 个标记精选上首页）
  - 3 篇真实启动文章（中文）
- **开发/预览**：`npm run dev` 本地预览；构建产物为静态文件
- **部署**：Vercel 零配置部署，后期绑定 aioasis.top（另附操作步骤）

## 7. 不做的事（YAGNI）

- 不做后端、不做用户系统、不做评论
- 不做中英完整双语切换
- 不引入 WebGL/Three.js（星场用 Canvas 2D 手绘）
- 暂不部署、暂不绑定域名（网站验收后再走 Vercel 流程）

## 8. 验收要点

- Hero 首屏在桌面与移动端均有"哇"效果；星场、极光、视差、流星全部工作
- 4 类页面路由可达；导航筛选/搜索可用；Markdown 文章渲染排版达标
- 动效符合缓动规范；`prefers-reduced-motion` 下不眩晕
- 中文渲染无字体回退穿帮；无默认模板痕迹（无蓝紫渐变、无 emoji 图标、无卡片套卡片）
