# 小游戏接入 AI绿洲（aioasis.top）说明书 · 静态挂载版

> 这份文件是给负责开发小游戏的 Agent 看的。照做即可被站长一键收录上线。
> 本站是静态站点（Vercel 托管，无后端），你的游戏会以 iframe 形式挂在
> `aioasis.top/#/toys` 游戏厅里，与主站沙盒隔离——所以你的游戏内部怎么写都行，
> 只需要满足下面几条硬性要求。

## 交付物（唯一硬性要求）

**一个纯静态文件目录**：`index.html` 入口 + 所需 js/css/资源，双击 `index.html` 就能玩。

- 技术栈不限：原生 HTML/JS、Canvas、任何框架都可以，只要最终能构建成纯静态文件
- **所有资源引用必须用相对路径**（`./xxx` 或 `xxx`），因为游戏会被挂到子路径
  `/toys/<游戏名>/` 下。禁止 `/` 开头的绝对路径
- 如果用 Vite 构建：`vite.config` 里设 `base: './'`；其他构建工具同理设相对 base
- 游戏本身需要是响应式的，**手机触屏可玩**，不依赖 hover 和键盘（可以有键盘增强，但不能只有键盘）

## 禁止项

- ❌ 站外资源：不引用任何 CDN 的 js/css/字体/图片（国内可直连原则）。需要的库全部打进自己的 bundle
- ❌ 后端依赖：不能需要任何服务端接口、数据库、登录
- ❌ 硬编码视口尺寸：不要写死 1920×1080 之类，游戏画布要适配容器大小
- ❌ 自动播放声音：声音必须由用户交互触发（浏览器策略，违反会被静音拦截）

## 建议项（做了体验更好）

- 浅色/深色两套配色或中性配色（游戏厅卡片墙是玻璃拟态深/浅主题，游戏内部独立，不强制适配）
- 成绩/进度存 `localStorage` 时键名加游戏名前缀（如 `snake-highscore`），避免和其他游戏撞键
- 尊重 `prefers-reduced-motion`：非必要动画在系统减弱动效时关闭
- 文件体积尽量小（单游戏总体积建议 < 2MB）

## 交付时附带的信息

把这些写在仓库 README 或交付说明里，站长收录时要用：

```yaml
name: 游戏中文名
nameEn: GAME NAME        # 英文小标
description: 一句话简介（20 字以内，会被展示在卡片上）
tags: [标签1, 标签2]      # 如：休闲 / 反应 / 解谜 / 街机
entry: index.html        # 入口文件名（默认 index.html 可省略）
author: 你的名字或署名
```

## 验收自查清单

- [ ] 双击 `index.html` 能直接玩（不依赖任何 dev server）
- [ ] 所有资源相对路径，挂到 `/toys/xxx/` 子路径下不死
- [ ] 手机上能玩（Chrome DevTools 设备模拟过一遍）
- [ ] 无任何站外请求（DevTools Network 面板检查，全部是同目录文件）
- [ ] 无自动播放声音
